# 🌌 Ecos Entre Universos

### *El Lugar Donde Coincidimos en el Tiempo*

> "Cuando el mundo pese demasiado, aquí hay un universo que solo tú
> puedes recorrer."

------------------------------------------------------------------------

## 🧭 Descripción

**Ecos Entre Universos** es un juego web interactivo narrativo diseñado
como una experiencia íntima y significativa.

Más que un juego, es un viaje a través de universos paralelos donde dos
realidades colisionan y comienzan a construir algo nuevo.

El proyecto combina dos propósitos:

-   **Épico:** Una historia sobre galaxias que se encuentran, colisionan
    y evolucionan juntas.\
-   **Terapéutico:** Un espacio seguro para explorar emociones, liberar
    carga mental y reconectar con la creatividad.

------------------------------------------------------------------------

## 🎮 Mecánica del Juego

Cada fase sigue una estructura cuidadosamente diseñada:

1.  Exploración de elementos interactivos con historias independientes\
2.  Desbloqueo de una pista críptica\
3.  Interacción con el creador para obtener una contraseña (fuera del
    juego)\
4.  Resolución de un puzzle basado en conexiones ocultas (*grafos
    narrativos*)\
5.  Desbloqueo de la siguiente fase

Las conexiones entre historias cambian en cada fase: emocionales,
temáticas, cronológicas o basadas en referencias.

------------------------------------------------------------------------

## 🌠 Fases del Juego

### I. Abandono de la Abadía

Soltar lo que pesa antes de comenzar\
*Tono: ceremonial · oscuro · liberador*

### II. Bastión Hueco

Explorar lo invisible y lo implícito\
*Tono: misterioso · íntimo · denso*

### III. Buscando el Vacío

El vacío como posibilidad\
*Tono: expansivo · onírico · sci-fi*

### IV. Un Nuevo Universo

Crear desde lo vivido\
*Tono: cálido · esperanzador · definitivo*

> El viaje completo sigue un arco:\
> **Abandonar → Analizar → Destruir → Crear**

## 🧠 Conceptos Clave

-   **Grafos narrativos:** conexiones ocultas entre historias\
-   **Pistas físicas:** interacción real entre creador y jugadora\
-   **Sistema de checkpoints:** progreso mediante códigos únicos\
-   **Cifrado César:** protección de contraseñas dentro del código

## 🔐 Sistema de Progreso

El juego utiliza dos tipos de contraseñas:

-   **Contraseña de puzzle:** desbloquea contenido dentro de la fase\
-   **Contraseña de checkpoint:** permite continuar el progreso en
    cualquier momento

No se utiliza almacenamiento local.\
El progreso es responsabilidad de la jugadora.
